3분이면 관계가 보입니다

거래·KYC·실소유자(UBO) 관계를 그래프로 펼쳐 자금세탁 패턴을 찾는 도구입니다. 설치 없이 브라우저에서 바로 쓰고, 입력한 데이터는 밖으로 나가지 않습니다. 아래 순서대로 한 번만 따라 해 보세요.
관계 탐색기 열기 →

1가장 빠른 시작

고민하지 말고 「예시」 버튼부터 누르세요. 미리 짜둔 자금세탁 시나리오(분할입금→집금→환전→회수)가 그래프로 그려지고, 오른쪽에 탐지된 패턴이 확률과 함께 나타납니다. 이걸로 도구가 뭘 하는지 30초면 감이 와요.

💡 처음이라면: 예시 → 그래프 구경 → 오른쪽 패턴 카드 읽기 → 슬라이더 만지작. 이 순서면 충분합니다.

2내 데이터 넣기

입력은 한 줄에 거래 하나, 쉼표로 구분합니다.

출발 , 관계 , 도착 , 금액 , 일자 계좌A , 이체 , 법인1 , 9500000 , 2026-01-03 09:15:02
  • 금액·일자는 선택입니다. 없으면 비워도 돼요.
  • 관계가 지분이면 네 번째 칸은 금액 대신 지분율(%): 홍길동 , 지분 , 법인1 , 60
  • 일자에 시각(09:15:02)까지 넣으면 초 단위 분석·급속통과 탐지가 켜집니다.

엑셀이 편하면 「엑셀 템플릿 받기」로 양식을 받아 채운 뒤 「엑셀·CSV 불러오기」로 올리면 됩니다. 열 순서가 달라도 알아서 인식해요.

🔒 실명·실계좌는 넣지 마세요. 모든 처리는 브라우저 안에서만 이뤄지지만, 캡처·화면 노출에 대비해 처음부터 가명(A001, 법인1)으로 넣는 걸 권합니다. 실데이터를 넣어야 한다면 「식별자 가명화」 체크박스를 켜세요 — 이름이 자동으로 가명(개인_a1·법인_b2)으로 바뀝니다.

3그래프 다루기

  • 노드 클릭 → 그 대상의 유입/유출 금액, 통과율, 거래 목록이 옆에 떠요
  • 거래선 클릭 → 금액·일자·관계 상세
  • 드래그 → 화면 이동 / 노드를 끌어 위치 정리
  • 줌 → ＋ － 버튼, 또는 Ctrl(⌘) + 휠 (그냥 휠은 페이지 스크롤)
  • 노드 검색창 → 큰 그래프에서 특정 대상 찾기

그래프 색의 의미:

빨강 선 = 순환거래 (자금이 출발점으로 돌아오는 고리)
라임 선 = 클릭한 노드의 직접 연결 강조
빨강 테두리 = 허브 (집금·분산 노드)

4패턴 읽기

오른쪽에 탐지된 패턴이 확률(%)과 함께 나옵니다. 색이 초록→노랑→빨강으로 갈수록 의심도가 높아요. 각 카드엔 "왜 중요한가 / 확인사항"이 같이 적혀 있습니다.

순환거래 — 자금이 A→B→C→A로 돌아오는 고리. 거래 실질을 가장하는 전형.
집금 / 분산 — 여러 계좌가 한 곳으로 모이거나(집금) 한 곳에서 퍼짐(분산).
스머핑 — 보고 기준금액 바로 아래로 거래를 쪼갬.
급속 통과 — 입금 직후 수초~수십초 내 재이체(자동화·통과거래 의심).
레이어링 — 여러 단계를 거쳐 자금을 이동(출처 추적 방해).
동일인 의심 — 다른 명의가 같은 상대들과 똑같이 거래(차명 의심).

위쪽 「종합 리스크」는 이 패턴들을 종합한 점수예요.

5임계값 조절 (핵심)

왼쪽 슬라이더를 움직이면 탐지 기준이 바뀌고, 패턴·확률·종합 리스크가 실시간으로 따라 움직입니다. 슬라이더 옆 숫자(예: "4건 탐지")로 변화가 바로 보여요.

  • 허브 최소 연결 수 — 몇 개 이상 연결돼야 허브로 볼지
  • 스머핑 기준금액 — 어느 금액 직하를 분할로 볼지
  • UBO 지분 임계 — 실효지분 몇 %부터 실소유자로 볼지 (보통 25%)
  • 급속 통과 간격 / 레이어링 단계 — 민감도 조절
💡 임계값을 바꿔보며 "기준을 어떻게 잡느냐에 따라 위험도가 어떻게 달라지는지" 보는 게 이 도구의 핵심입니다.

6결과 내보내기

  • PDF — 종합 리스크·패턴·중심성·UBO·그래프가 담긴 보고서 (한글 지원)
  • PNG — 그래프 이미지
  • 케이스 저장/열기 — 작업 내용을 .json으로 저장했다 다시 불러오기

7STR 문안 초안 생성 NEW

분석이 끝나면 우측 종합 리스크 아래 📝 STR 문안 초안 생성 버튼이 나타납니다. 누르면 탐지 결과가 보고 문안 형식으로 자동 작성됩니다.

  • 1. 분석 개요 — 명의 구성(개인·법인·계좌), 거래 건수·기간·총액
  • 2. 탐지 패턴 및 혐의 사유 — 패턴별 의심도%·경로·서술문
  • 3. 종합 의견 — 종합 의심도와 특금법 제4조 검토 문구

📋 복사를 누르면 클립보드로 복사되어 사내 보고 양식에 바로 붙여넣을 수 있습니다. 가명화를 켠 상태로 생성하면 문안에도 가명이 들어가 외부 공유·교육용으로 안전합니다.

자동 생성 초안입니다. 최종 보고 여부와 내용은 거래 실질·고객확인 정보를 반영해 보고책임자 판단으로 확정하세요.

8표시 필터 — 노이즈 걷어내기 NEW

실데이터는 정상 거래가 뒤섞여 있죠. 좌측 표시 필터로 분석 범위를 좁힐 수 있습니다.

  • 최소 금액(만원) — 예: 500 입력 시 500만원 이상 거래만 분석
  • 기간 — 시작~종료일 지정 (예: 사건 발생 주간만)

필터가 적용되면 "17/20건 표시"처럼 몇 건이 남았는지 보여줍니다. 지분 관계는 필터와 무관하게 유지됩니다(소유 구조는 금액·날짜 개념이 아니므로).

9그래프 읽는 법 — 도형·색·선 NEW

  • 도형 — 개인=원 ● / 법인=사각형 ■ / 계좌=다이아몬드 ◆ / UBO=육각형 ⬢
  • 크기 — 연결이 많을수록 커짐 (허브가 한눈에)
  • 빨강 링 글로우 — 집금·분산 허브
  • 실선 = 자금 흐름(이체) / 보라 점선 = 지분(소유 구조)
  • 빨강 대시선 = 순환거래 경로
  • 마우스 올리기 — 그 노드와 연결된 이웃만 밝아짐

?자주 묻는 질문

내 데이터가 서버로 가나요?
아니요. 모든 분석이 브라우저 안에서만 이뤄지고 어디에도 저장·전송되지 않습니다. 인터넷을 꺼도 동작합니다.
이게 실제 STR 판정을 대신하나요?
아닙니다. 의심 구조를 빠르게 떠올리게 돕는 연습·탐색용 도구이며, 실제 판단은 내부통제 절차를 따라야 합니다. 확률(%)도 구조 신호의 추정치예요.
데이터가 많아도 되나요?
수십~백여 개 노드까지 무리 없이 그려집니다. 너무 많으면 「재배치」·검색·줌으로 정리하세요.
모바일에서도 되나요?
됩니다. 다만 큰 그래프는 PC 화면이 편해요.
