## 2. 이번 작업으로 새로 만든 것

### 관계 탐색기 고도화 (핵심)
- **STR 문안 초안 자동 생성** — 분석 결과를 보고 문안 형식(개요 / 패턴별 혐의사유 / 종합의견)으로 자동 작성, 클립보드 복사. 가명화 상태로 생성하면 문안도 가명 처리
- **표시 필터** — 최소 금액(만원)·기간으로 노이즈 제거. "17/20건 표시"로 필터 결과 표시 (지분 관계는 구조 정보라 필터 제외)
- **그래프 디자인** — 유형별 도형(개인 ● / 법인 ■ / 계좌 ◆ / UBO ⬢), 연결 수 비례 크기, 허브 빨강 글로우, 지분=보라 점선, 순환=빨강 대시, 호버 시 이웃 강조

### 수법 인텔리전스 (신규 도구)
- 국내외 뉴스·수사 사례에서 **자금세탁 수법 10종**을 추출해 매일 순위화
- 점수 = 보도 빈도 + 수법 심각도 + **당국 적발(검거·기소) 가중**
- 수법별 **STR 점검 포인트** + **SQL 테마룰 템플릿**(펼치기·복사) 제공

### 자동 발송 (신규)
- `notify/send_telegram.py` — 매일 다이제스트(키워드 / 수법 동향 / 업종위험 1위·재평가 후보 / 주요 기사 3건) 자동 발송. **추천**
- `notify/send_kakao.py` — 카카오톡 "나에게 보내기" (한계 있음 — 가이드 13-2)

### 사이트 정비
- 전 페이지 **OG 태그** 삽입 → 카톡·링크드인 공유 시 썸네일 정상 노출
- 브리핑·체커·레이더·자료실에 **홈 링크 복구**
- 허브에 **"이럴 때, 이 도구" 워크플로** 섹션 + 스탯 스트립
- 사용 가이드에 신기능 3개 장(STR 문안 / 표시 필터 / 그래프 읽는 법) 추가

```

 ├─ 브리핑 수집        → briefing/data.json
 ├─ 업종 위험 RA 수집  → business-risk/ra_news.json
 ├─ 수법 인텔리전스     → typology/methods.json
 ├─ 자금흐름 수집       → flow/flow_data.json
 ├─ (월요일) 제재 명단 → checker/*
 ├─ 변경분 자동 커밋·푸시
 └─ 텔레그램/카카오 발송 (선택 — Secrets 설정 시)
```

## 5. 배포 전 반드시 확인 (자주 막히는 2가지)

1. **`.github` 폴더 포함** — 숨김 폴더라 업로드 때 누락되기 쉬움. 빠지면 자동 갱신이 안 됨
2. **도메인 잠금 해제** — 관계 탐색기는 허가된 주소에서만 열림. 새 주소로 배포하면 본인도 막힘
   → `relation/index.html`의 `ALLOW` 배열에 배포 주소 추가 (가이드 10장)
